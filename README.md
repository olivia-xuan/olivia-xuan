#### Featured project: [CCAF Quest](https://ccaf-quest-rust.vercel.app)

A free study site for the Claude Certified Architect – Foundations exam.

- **312 original practice questions** built around the official exam task statements
- **Accounts and saved progress**, so learners pick up where they left off
- **A live leaderboard** to keep study groups motivated
- **"Ask Claude about this"** on every question for a deeper explanation

**How I approached it:** I started from the learner's problem (scattered material, no way to see weak spots), designed the experience, then chose a lean architecture: a static front end on Vercel, with Supabase handling sign-in and storing results behind row-level security, so each person only sees their own data. AI coding tools helped me move fast; the product decisions and trade-offs are mine.

👉 **[Try it](https://ccaf-quest-rust.vercel.app)** · [Code](https://github.com/olivia-xuan/ccaf-quest)
